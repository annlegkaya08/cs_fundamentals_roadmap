Рекурсия - процесс (или функция), вызывающий себя же напрямую или через другой процесс (функцию) -> два вида вызова рекурсивных функций:
1) прямой int a(){ return a()}
2) косвенный int a(){ return b()} b(){returna()}

Базовый случай - условие прекращения рекурсии, не переходя в бесконечный цикл
Рекурсивный шаг - часть, где задача сводится к решению более простой
Глубина рекурсии - количество шагов, после которых прямой ход рекурсии переходит в обратный


Рекурсия служит образцом индуктивного доказательства, ведь сама индукция имеет рекурсивную природу. Каждый шаг индукции представляет из себя рекурсивный вызов, переводящий нас к следующему утверждению

Индукцией же и проверяется корректность рекурсивных алгоритмов, сперва проверяется базовый случай, а далее выдвигается предположение, что функция корректна для N, далее проверяясь и на N+1 и далее
