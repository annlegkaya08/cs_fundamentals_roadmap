**Высказывание** — это повествовательное предложение, о котором однозначно можно сказать: истинно оно или ложно.

**Предикат** (или высказывательная форма) — это предложение с переменными. Оно не является высказыванием само по себе, но становится им, если вместо переменных подставить конкретные значения из некоторого множества (предметной области).

- P(x): «x — чётное число». Если x = 4, получаем истинное высказывание; если x = 3 — ложное.

**Кванторы** — это специальные символы, которые позволяют из предиката построить высказывание, то есть «связать» переменную и сказать что-то обо всей совокупности объектов.

- Квантор всеобщности (обозначается ∀, читается «для всех», «для каждого», «для любого»). Запись ∀x P(x) означает: «для любого x из предметной области предикат P(x) истинен». Высказывание ∀x P(x) истинно, если P(x) истинен при любой подстановке x из M (области определения предиката). Если найдётся хотя бы одно x, для которого P(x) ложен, то ∀x P(x) ложно. 

- Квантор существования (обозначается ∃, читается «существует», «существует такой x»). Запись ∃x P(x) означает: «существует x такой, что P(x) истинен». Высказывание ∃x P(x) истинно, если в предметной области найдётся хотя бы одно значение x, при котором P(x) истинен. Если для всех x из M предикат ложен, то ∃x P(x) ложно. 


**Таблица истинности** показывает значение логического выражения при всех комбинациях входных значений.

### **Логическая функция (булева функция)**

Функция `f: {0,1}ⁿ → {0,1}`, ставящая в соответствие набору из `n` логических переменных одно значение истинности.
