**Доказательство** - логическое рассуждение, с помощью которого устанавливается истинность математического утверждения на основании известных фактов, определений, аксиом и ранее доказанных теорем.

В алгебре логики доказательства используются для установления истинности высказываний, равносильности логических формул и проверки правильности математических утверждений.

### **1. Прямое доказательство**

**Прямое доказательство** - метод, при котором истинность утверждения устанавливается последовательным логическим переходом от известных условий к требуемому заключению.

Основная схема:

P -> A_1 -> A_2 -> Q 

Где:

- P — условие (предположение);
- A_1,A_2 — промежуточные логические утверждения;
- Q — заключение, которое необходимо доказать.
### **2. Доказательство от противного**

**Доказательство от противного** - метод, при котором предполагается, что утверждение неверно, после чего из этого предположения выводится противоречие с известными фактами или условиями задачи.

Основная схема:

1. Предположить, что утверждение \(Q\) ложно.
2. Вывести из этого предположения логические следствия.
3. Получить противоречие.
4. Сделать вывод, что исходное утверждение истинно.

В логической форме:

¬Q⇒⊥

Где ⊥ обозначает противоречие (ложное высказывание).

### **3. Доказательство контрапозицией**

**Контрапозиция** -метод доказательства утверждения P⇒Q через доказательство равносильного ему утверждения ¬Q⇒¬P

Основное логическое свойство:

P⇒Q≡¬Q⇒¬P

То есть вместо доказательства того, что из \(P\) следует \(Q\), доказывается, что из отрицания \(Q\) следует отрицание \(P\).


**Отличие от доказательства от противного:** при контрапозиции доказывается конкретное равносильное утверждение, а при доказательстве от противного предполагается отрицание исходного заключения и выводится противоречие.

### **4. Доказательство разбором случаев**

**Разбор случаев** — метод, при котором рассматриваются все возможные варианты выполнения условия, и утверждение доказывается отдельно для каждого из них.

Основная схема:

P 1 ​ ∨P 2 ​ ∨…∨P n ​

Необходимо доказать:

(P 1 ⇒Q)∧(P 2 ⇒Q)∧…∧(P n ⇒Q)

При этом случаи должны охватывать все возможные варианты.

### **5. Конструктивное доказательство**

**Конструктивное доказательство** — метод, при котором для подтверждения существования математического объекта приводится конкретный пример этого объекта или способ его построения.

Основная схема:

∃x P(x)

Для доказательства существования достаточно предъявить конкретное значение \(a\), для которого:

P(a)=Истина

### **6. Математическая индукция**

**Математическая индукция** - метод доказательства утверждений, зависящих от натурального числа \(n\). Он позволяет доказать, что утверждение выполняется для всех натуральных чисел (или для всех чисел начиная с определённого значения).

Метод основан на двух основных этапах:

1. **База индукции** — проверка истинности утверждения при начальном значении \(n\).
2. **Индукционный переход** — доказательство того, что из истинности утверждения для некоторого \(n=k\) следует его истинность для \(n=k+1\).

Если оба этапа выполнены, утверждение считается доказанным для всех натуральных чисел начиная с начального значения.

### **7. Виды математической индукции**

Помимо обычной (простой) математической индукции выделяют несколько её разновидностей.

**1. Простая математическая индукция**

Для доказательства утверждения при \(n=k+1\) используется предположение о его истинности только при \(n=k\).


**2. Полная (сильная) математическая индукция**

При доказательстве утверждения для \(n=k+1\) предполагается, что оно верно не только для \(n=k\), но и для всех предыдущих натуральных значений от начального до \(k\).

Используется, когда для доказательства очередного шага необходимо опираться на несколько предыдущих случаев.

**3. Структурная индукция**

Применяется для доказательства свойств объектов, построенных по определённым правилам: логических формул, деревьев, последовательностей, выражений и других рекурсивно заданных структур.

Состоит из двух этапов:

- Проверка свойства для базовых элементов структуры.
- Доказательство того, что свойство сохраняется при построении новых элементов из уже существующих.

Например, структурную индукцию можно использовать для доказательства свойств логических формул, построенных из переменных с помощью операций отрицания, конъюнкции и дизъюнкции.

**4. Двойная индукция**

Метод, при котором доказательство проводится одновременно по двум натуральным параметрам, например \(n\) и \(m\).

Используется для утверждений, зависящих от двух переменных, например свойств матриц, таблиц и двумерных последовательностей.

### **8. Сравнение методов доказательства**

|Метод|Основная идея|
|---|---|
|Прямое|Последовательно вывести заключение из условия|
|От противного|Предположить отрицание утверждения и получить противоречие|
|Контрапозиция|Доказать, что из отрицания заключения следует отрицание условия|
|Разбор случаев|Рассмотреть все возможные варианты отдельно|
|Конструктивное|Привести конкретный объект или способ его построения|
|Простая индукция|Доказать базу и переход от \(k\) к \(k+1\)|
|Полная индукция|Использовать истинность всех предыдущих случаев|
|Структурная индукция|Доказать свойство для базовых элементов и правил построения|
|Двойная индукция|Доказать утверждение по двум параметрам|
